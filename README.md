## About the Project
### **Hovering-Ghost** - It Is a Halloween theme 3d printable Hovering Ghost with Crank-and-slider mechanism Fully design in fusion 360. in Which mini Ghost start Hovering when we Rotate the handle.


## why i made this?
### main reason is that Learning, this is my first time making Crank-and-slider mechanism . and second reason that Halloween is nearby so I give it Halloween theme.

### Recommended Print Specifications

> [!TIP]
> Use PETG filament for All Mechanical parts.

| Specification | Default Value / Range |
| :--- | :--- |
| **Printer Nozzle** | 0.4 mm Stainless Steel |
| **Layer Height** | 0.2 mm |
| **First Layer Height** | 0.2 mm |
| **Nozzle Temperature** | Depends on your Filament |
| **Build Plate Temperature** | Depends on your Filament |
| **Sparse Infill Density** | 10% |
| **Max Toolhead Speed** | 500 mm/s |
| **Max Acceleration** | 8000 mm/s² |
| **Support** | normal 25° |
